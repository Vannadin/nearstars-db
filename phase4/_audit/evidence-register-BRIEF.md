## Why this is its own run (not done in the fix-run session)

1. Trimming evidence is redistribution, not compression — the "storytelling"
   is real physics argument (e.g. Hades's two refuted counter-arguments);
   cutting it without a new home loses substance. The home per contract is
   the methodology docs, so it is a two-file move.
2. The honesty promise lives exactly in the long blocks: the override
   audit's reference-standard rows (Chaos surface, Chaos satellites) are the
   longest. A mechanical de-storytelling pass damages the best rows first.
3. The 13 clipped blocks need new check sentences written per row (research,
   both languages), not editing.
4. Risk: the session already stacked 13+ dense commits on this file; big
   text passes are where corruption happened historically (4b8d73b).
