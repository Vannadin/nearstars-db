# 우리가 인용한 논문들에서 찾은 결함

**기록이 아니라 색인입니다.** 각 결함은 발견된 자리에 그대로 적혀 있습니다 — 인용문은 출처 안의 제자리에, 확인한 사람의 이름과 함께요. 이 파일이 있는 이유는 두 가지입니다. 세션이 *"이 논문 우리가 이미 읽었나, 그리고 물렸나"* 를 노트 전부를 뒤지지 않고 물을 수 있게, 그리고 **같은 저자·같은 그룹의 새 논문**이 들어올 때 앞선 발견이 함께 딸려오게.

**범위는 출처의 결함이지 우리 전사의 결함이 아닙니다.** 우리 실수는 브리프와 `engine/SESSION-HANDOFF.md` 규칙 절에 있습니다 — 멀쩡한 논문을 잘못 읽은 것은 여기 들어오지 않습니다.

**행을 추가할 때**는 양의 이름을 대고, 논문이 인쇄한 것과 옳은 것을 나란히 적고, 정정의 출처를 밝히고, 전말이 적힌 노트를 가리킵니다. **틀린 값이 조용히 틀린 답을 낼 수 있으면 게이트가 그걸 잡는지도 적습니다.**
