# NearStars

커리어 세이브를 한참 진행하다 보면, 재사용 로켓이 날아다니고 기술 트리도 거의 다 채워진 어느 시점에 탐사선을 다른 행성이 아니라 항성 자체로 겨냥하고, 몇 년의 임무 시간을 그곳까지 코스팅하며 흘려보내게 됩니다. NearStars는 그렇게 도착한 순간이 기다린 보람이 있도록 만들어진 모드입니다. 완전히 사실적인 태양계를 뒤로하고 실제 이웃 항성에 도달하면, 그곳에서 기다리는 모든 세계는 천문학자들이 실제로 측정한 값으로 만들어져 있습니다.

이 모드는 Kerbal Space Program 1.12.x용으로, Real Solar System 설치([Sol-Configs](https://github.com/RSS-Reborn/Sol-Configs) 경유) 위에 얹혀 약 50광년 반경의 실제 태양계 이웃을 채워 넣습니다. 알파 센타우리, 바너드 별, 타우 세티, TRAPPIST-1 등입니다.

KSP에서 가까운 별로 날아가는 아이디어 자체는 새로운 것이 아닙니다. NearStars를 다르게 만드는 것은 아무것도 지어내지 않는다는 원칙입니다. 모든 항성의 온도와 색, 모든 행성의 궤도와 질량, 모든 잔해 고리는 출처가 된 논문이나 카탈로그를 인용으로 달고 있습니다. 어떤 망원경으로도 분해되지 않은 표면의 색이나 점으로만 관측된 행성의 대기처럼 값이 아예 측정된 적 없는 경우, 이 모드는 조용히 추측하지 않습니다. 결정 하나하나를 방어 가능한 답으로 도출하고, 어떤 논문이 그 값을 제약하는지 기록하며, 신뢰도를 표시합니다. 게임플레이의 다양성을 위해 순전히 창작된 소수의 세계도 같은 정직성의 기준을 적용받습니다. 각각 물리 법칙에 맞는지 검증되고, fiction으로 표시되며, 실제 검출 결과 사이에 몰래 끼워 넣지 않습니다.

이런 원칙은 다른 팩들이 흔히 단순화하는 시스템에서 가장 큰 힘을 발휘합니다. 여기서는 다중성계가 실제로 다중성계답게 움직입니다. 알파 센타우리의 A와 B는 실제 관측된 80년 주기 궤도를 그대로 돌고, 전체 로스터는 장기 n-body 시뮬레이션으로 검증되어 언뜻 보기에만 맞는 게 아니라 Principia의 중력 아래에서도 실제로 안정적으로 유지됩니다.

> **상태: 개발 중, 아직 출시되지 않았습니다.** 데이터 엔진(이 저장소)은 큐레이션된 데이터베이스 마일스톤에 도달했으며, 최종 KSP 설정 파일 생성은 의도적으로 맨 마지막 단계로 남겨두었습니다. 출시 소식은 이 저장소를 지켜봐 주세요.

## v1 로스터

모드 자체는 훨씬 더 큰 연구 데이터베이스에서 뽑아낸 일곱 개 시스템만을 압축해 담아 출시됩니다. 선정 기준은 거리, 행성 구성, 그리고 순전한 다양성이며, 어느 두 목적지도 같은 느낌을 주지 않도록 골랐습니다.

| 시스템 | 거리 | 무엇이 있는가 |
|---|---|---|
| [알파 센타우리](star-systems.md#alpha-centauri) | 4.4 광년 | G+K 쌍성과 행성 3개를 가진 프록시마 |
| [루만 16](star-systems.md#luhman-16) | 6.5 광년 | 가장 가까운 갈색왜성 쌍성 |
| [바너드 별](star-systems.md#barnards-star) | 6.0 광년 | 지구보다 작은 행성 4개 |
| [타우 세티](star-systems.md#tau-ceti) | 11.9 광년 | 태양과 닮은 항성, 슈퍼지구 4개 |
| [40 에리다니](star-systems.md#40-eridani) | 16.3 광년 | K형 왜성 + 백색왜성 + 플레어별 삼중성 |
| [포말하우트](star-systems.md#fomalhaut) | 25.1 광년 | 상징적인 잔해 고리를 가진 A형 별 |
| [TRAPPIST-1](star-systems.md#trappist-1) | 40.7 광년 | 공명 사슬을 이루는 지구 크기 행성 7개 |

이 일곱 시스템 뒤에는 전체 연구 데이터베이스, 즉 145개 시스템과 157개의 항성 구성원이 자리하고 있으며, 지금 바로 [라이브 뷰어](https://vannadin.github.io/nearstars-db/)에서 둘러볼 수 있습니다.
