시스템마다 계층(행성계·위성계)별로 두 방식을 교차 실행합니다. leapfrog(고정 10분 스텝)는 Principia 인게임 적분기와 정합하고, IAS15/TRACE+MEGNO는 결정론적 카오스와 장기 생존을 판정합니다. 장기 구간은 연수가 아니라 안쪽 궤도 바퀴 수(기준 10⁸바퀴)로 맞춥니다.Each system is run both ways on every hierarchy it has. Leapfrog (fixed 10-min step) matches Principia's in-game integrator; IAS15/TRACE+MEGNO judges deterministic chaos and long-term survival. Long horizons are matched in inner-orbit count (10⁸ orbits), not years.
